✨ Major Achievements

•
On-device LLM Inference on Mobile: Successfully deployed and ran a local LLM directly on a smartphone, achieving fully offline inference without cloud dependency.

•
NVIDIA Jetson Edge Inference Server: Configured an NVIDIA Jetson as a local server to handle LLM inference requests for connected edge devices, enabling low-latency, offline AI processing.

•
Local LLM Server for AI Assistant: Set up a self-hosted local LLM server on a laptop to power a fully local AI assistant, ensuring privacy and an entirely offline pipeline.
